What is this file?

outreach-leads.html is the daily outreach dashboard. After each batch of websites is built and uploaded to GitHub Pages, this file gets updated with the new leads so the owner can copy the DM message and send it to each Instagram profile.

✅ What to REPLACE on every daily update
  • All <div class="card" ...> elements inside #leadsList — full clean overwrite, no old entries kept
  • The filter tabs (only category tabs) — update to match the new batch categories and counts
  • The statsCount text (e.g. "Showing 60 leads")
❌ What to NEVER touch
  • The #samplesPanel div and all its contents (10 template links)
  • The #agentPanel div (this panel)
  • The "★ Main Template Samples" tab and the "📄 Agent Guide" tab
  • The showSamples() and showAgentGuide() JS functions
  • The modal (#copyModal), toast (#toast), and copyMessage() / closeModal() functions
  • All CSS styles in the <style> block
